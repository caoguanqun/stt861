## Course Description

STT 861 is a graduate-level introduction to the mathematical foundations of probability and statistical inference, designed for first-year master's students in Statistics. The course develops rigorous probability theory from first principles — from set theory and the Kolmogorov axioms through the Central Limit Theorem and Delta Method.
